# Objects365 V2 365 类改类门控

以官方 train 标注和图像为监督来源。首批从训练 patch0 按重复实例的类别轮转选至多 8192 张，排除 OmniLabel 的同源图名及已知工作集的重复图像字节。按图像哈希划分 70% 训练、10% 优化监控、10% 策略校准、10% 内部开发验证。候选池筛图依赖人工标注，候选生成只读取图像。内部验证适用于多实例富集图，正式 Objects365 验证仍是独立用途。

Grounding DINO 以一条完整词表提示在同组 query 上计算 365 类原生分数。仅在本实验实例增加文本长度容量，冻结权重，按短提示原生输出等价性及长提示完整列检查。维持 800/1333 图像预处理、原生候选回放、跨层 Qwen 隐状态和同图 GraphLLM 供体。基础和辅助父类的类别 ID 独立。无损正例与确认不支持动作二元监督，未知动作仅进入策略评估。

使用 2,957,826 参数 MLP，固定随机初始化和既有图及二元类平衡。48 轮 AdamW，学习率 .0005、权重衰减 .03、批量 128、余弦衰减至零。监控图的图平衡交叉熵按相同的既有 bootstrap 容差、末五轮平台及波动检查。保留最佳与最终权重，合格后锁定策略再打开内部验证。

每图以三视图平均支持分选择首位，正向要求大于 .5。混合熵分歧上限使用校准确证正例第 90 百分位，平均分与混合熵均按零误改且零原匹配损失在策略校准选择阈值。开发验证记录改对、误改、原匹配损失和 AP/AP50/AP75，比较原生 365 类检测。COCO 验证的历史共享 48 类视角单独解释，365 类训练覆盖的旧 COCO novel 概念视为已接受监督。
