# 先保护原匹配，再选 GraphLLM 改类

保持现有低分框、图提名、原生类差增强的 GraphLLM 支持分和供体视图。用既有 Objects365 类别核验缓存中的原类及提名类原生分、附近查询和输出覆盖、CLIP 原裁片和聚焦裁片证据，学习一次类别替换是否误改原类或损失已有真阳性。风险输出单独使用接收框证据。GraphLLM 支持只作为训练时的高分难例权重，和推理时的收益排序。已核验但无害和已核验有害按图各占一半，各类中 25% 权重给原方法支持最高四分位。未确证动作不进入监督。

按原 train/rare_train 与 monitor 互斥图训练一版 16→16→1 风险读出，输出层从零初始化，AdamW，0.015 余弦衰减到零，权重衰减 0.05，全批 120 步。每步记录监控 BCE。最后五步的训练损失变化小于 2.5%，监控斜率、范围及末轮与最佳差按初始逐图自举 95% 区间半宽判定，至少 0.005。通过且最佳非初始后才运行策略和历史开发回放。

冻结五个监控有害动作风险分位（1%、5%、10%、25%、50%）及无风险截断的候选工作点。先过滤风险和已有有效多供体视图的混合熵分歧，再从同一图剩余动作中按既有支持分取一条。无多供体分歧的候选仍经过独立风险核验。871 张策略图选择零已知误改和零原匹配损失的工作点，主预算零未确证，辅助预算 11 条未确证（冻结旧规则在策略图的数量）。在预算内优先真实 IoU 0.50、0.75 新增匹配，之后看语义改对。比较纯均值与含混合熵两种选择。790 张历史开发图仅作开发。开发出现非空低风险信号后，再锁定规则在项目未见图验证。
