# Objects365 接收框原类与提名类核验

针对上一轮原类已经对准、提名类缺乏实例支撑的有害动作。使用相同 Objects365 划分、同图供体提名与上一轮锁定的融合风险和收益分。新模型对接收框的原类和提名类使用同一个二元类别核验器。监督按实际接收框与类别标注的最高 IoU。IoU 至少 0.50 为正例，IoU 不超过 0.30 且该框与任一常规标注的最高 IoU 至少为 0.50 时为负例。相关 crowd 覆盖比例达到 0.50、边界及没有对准常规标注的动作跳过监督。训练动作来自既有训练及稀有类补样的核验缓存。

对照只读四项原生检测证据。视觉组另读接收框原始裁片和 DINO query 注意力聚焦裁片各自的冻结 CLIP 类别余弦分数和相对最高类别分的差。CLIP 只读取接收框裁片和类别文本。用标准化后相同的 6→48→24→1 MLP，检测证据对照将两个 CLIP 输入置零。各正负类等权，类内按图均衡，原始和聚焦视图平均 BCE。AdamW 学习率 0.0005、权重衰减 0.02、批量 1024、50 轮余弦至零，第 26 轮起平均权重，种子 20261111。独立监控图上以均匀二元分数和 2000 次图 bootstrap 确定统一容差，最小 0.005。末五轮训练变化至多 2.5%，监控斜率至多容差四分之一、振幅和最佳末轮差至多容差。保存最佳和最终权重。若不合格，从最佳续训 25 轮，学习率 0.0001 至零并全程平均。两组通过资格后才打开开发效能。

锁定上一轮融合组的风险上限和收益下限及每图首位，核验器仅对这条首位进行放行。原类用两视图最高支持，提名类用两视图最低支持。要求提名类支持及原类不受支持分数都至少达到同一个门槛。候选门槛固定为 0.50、0.60、0.70、0.80、0.90、0.95。只在策略图中选零已知误改及原匹配损失且保留最多新增匹配的门槛，平局优先确认改对和较少未确证、最后取较严格门槛。开发图比较原生检测、上一轮融合组与两个核验器。报告放行、严格改对、补回、原匹配损失、未确证和 AP/AP50/AP75，按图配对 bootstrap 2000 次。用独立原类与提名类分数复核上一轮明确有害动作。此轮沿用 790 张开发图，封存 COCO 不参与。
